LPR Analyzer — 動画から車番を検出

MP4 を読み込み、通過した車のナンバーと時刻を一覧にします。読み込み・デコード・検出・認識・追跡・描画はすべてブラウザ内の C++（WebAssembly）で動き、動画はどこにも送信されません。

1. 動画を選ぶ

    MP4 をここにドロップ、またはクリックして追加
    モデルを読み込み中…
    解析中のフレームがここに出ます
    （枠とナンバーは C++ 側で描いています）

    通過した車

    時刻プレートナンバー読み取り全体確度
    まだありません。

    時刻は動画の先頭からの経過時間で、そのナンバーが最初に見えた時刻です。行をクリックすると、いちばんよく読めたときの場面を上に表示します。 4 桁の数字は高い確度で読めますが、地名・分類番号・ひらがなはまだ誤りが多めです。
